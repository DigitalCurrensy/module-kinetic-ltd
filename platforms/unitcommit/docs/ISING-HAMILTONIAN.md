# Unitcommit — the power numbers

Do the power numbers add up?

The cabinet factor is applied first. The check then compares the power with what was asked. A mismatch is refused. A plan of on and off is not a dispatch.

The plan is built from groups. One charger is not one switch in the plan.

- On or off for group k in interval t
- Starting in that interval is a second yes or no
- The actual megawatts stay in the mismatch check

The mismatch check must see the same width as the plan. If the count does not match, the run is refused.

The cost of leaving a group on, and the cost of starting it, are the only costs in the plan. The cabinet factor changes the power limits before those costs are built. It is not a second copy of the cost.

True power balance is the mismatch number. The plan alone does not prove the megawatts.
