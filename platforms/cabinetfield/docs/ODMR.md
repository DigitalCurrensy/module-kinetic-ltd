# Cabinetfield — the cabinet measurement

Was the cabinet measured?

A nameplate is not a measurement. A serious fault with no calibration for that cabinet and that time is refused. The result is a factor from 0 to 1. That factor shrinks the power the next check may use.

The measurement is two frequencies around 2.87 GHz:

```
f+ = D + γ B
f- = D - γ B
γ = 28.024 MHz/mT
B = (f+ - f-) / (2γ)
```

A shift of 1 MHz or more from the calibrated center cuts the factor in half.
